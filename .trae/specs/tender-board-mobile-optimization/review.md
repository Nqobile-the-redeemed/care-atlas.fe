## Findings (Advisory Only, Non-Blocking)

1. **Nice-to-have: touch drag-to-dismiss** — Spec allowed for 10–15 line onTouch handlers; not implemented because current Minimize/Exit buttons provide 2 distinct exit paths plus backdrop tap minimize = 3 gestures for the 2 states. Safe to skip for MVP. Can be added later without structural changes.
2. **Nice-to-have: viewport resize event live-swap** — useMediaQuery hook (Task 2) correctly tracks media changes; user who rotates phone from portrait (mobile → sheet) to landscape (iPad width → drawer) at runtime will see morphology swap. Tested only indirectly via matchMedia listener in Task 2 TR-2.2; no explicit vitest for swap yet. Low risk because: swap just re-renders with isDesktop flag; shared TemplateComponent instance is preserved (key unchanged) so form state retained.
3. **Known WCAG gray area: desktop icon-only buttons.** Lines 177–198 uses 40×40 (p-2, 8 pad) buttons with aria-labels. Apple HIG recommends 44px; WCAG SC 2.5.5 Target Size Level AA = 24px. 40px exceeds 24px; passes WCAG 2.2 AA. If Apple Human Interface Guidelines conformance is required, bump p-2 to p-2.5 (44px) on these buttons. Deliberately left unchanged as it was pre-existing desktop-only UI.
